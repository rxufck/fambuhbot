# Бот семейного бюджета для Telegram

## Запуск (один раз настроить)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → получите **токен**.
2. Там же: `/setprivacy` → выберите бота → **Disable** (чтобы в общем чате бот видел обычные сообщения).
3. Установите Python 3.10+ (python.org) и выполните в папке бота:
   ```
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и впишите токен в `BOT_TOKEN`.
5. Запустите: `python bot.py`. Бот работает, пока запущена программа
   (для работы 24/7 нужен всегда включённый компьютер или дешёвый сервер/VPS).

## Как пользоваться

Создайте группу в Telegram, добавьте туда себя, Настю и бота. Данные общие для группы.

- `старт 130000` — стартовая сумма
- `-600 еда`, `минус 40к свадьба зал`, `450 такси` — расходы
- `+50000 зарплата`, `плюс 40 тыс проценты` — доходы
- `баланс`, `сводка` (или `сводка 11`), `последние`, `отмена`, `удалить 12`, `помощь` — можно и со слэшем: `/balance`, `/month`, `/last`, `/undo`
- Если категория не определилась, бот покажет кнопки и запомнит ваш выбор.
- В последний день месяца в `SUMMARY_HOUR` (по умолчанию 21:00) бот присылает сводку.

Категории и ключевые слова редактируются в начале `logic.py`.
